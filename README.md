# Prudentia Academy Case File

## How to Play
1. **Download**: Go to the [Releases](../../releases) page and download `PrudentiaAcademy-0.1-pc.zip`.
2. **Extract**: Unzip the downloaded `PrudentiaAcademy-0.1-pc.zip` file onto your PC.
3. **Launch**: Open the extracted folder and double-click `PrudentiaAcademy.exe` to start the game!

---
# 普魯登蒂亞學園事件簿

## 遊玩方法
1. **下載檔案**：點擊前往 [Releases](../../releases) 頁面下載 `PrudentiaAcademy-0.1-pc.zip`。
2. **解壓縮**：將下載完成的 `PrudentiaAcademy-0.1-pc.zip` 解壓縮至你的電腦。
3. **啟動遊戲**：開啟解壓後的資料夾，雙擊執行 `PrudentiaAcademy.exe` 即可開始遊玩！

# プルデンティア学園事件簿

## プレイ方法
1. **ダウンロード**：[Releases](../../releases) ページから `PrudentiaAcademy-0.1-pc.zip` をダウンロードします。
2. **解凍**：ダウンロードした `PrudentiaAcademy-0.1-pc.zip` ファイルをパソコン上に解凍（展開）します。
3. **ゲーム起動**：解凍したフォルダを開き、`PrudentiaAcademy.exe` をダブルクリックするとゲームが開始します！
